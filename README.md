# SKS-CNN-STREAMLIT-PROJECT
# CNN Image Classification and Streamlit Application

## Project Overview
This project consists of two parts:

1. **CNN Image Classification:** Classifies handwritten digits (0–9) using the MNIST dataset.
2. **Student Marks Calculator:** A Streamlit application that calculates student marks, percentage, grade, and result.

## Technologies Used
- Python
- TensorFlow / Keras
- CNN
- MNIST Dataset
- Streamlit
- NumPy

## CNN Model Results
- Dataset: MNIST
- Test Accuracy: 98.98%
- Test Loss: 0.0334
- Correct Predictions: 9,898

## Streamlit Application Features
- Student name and subject mark inputs.
- Total marks and percentage calculation.
- Automatic grade calculation.
- PASS/FAIL result.

## Sample Output
- Student Name: Shaik Shaheen
- Total Marks: 445/500
- Percentage: 89%
- Grade: A
- Result: PASS

## How to Run

Install dependencies:

```bash
pip install streamlit tensorflow numpy matplotlib
```

Run the application:

```bash
streamlit run PartB.py
```
